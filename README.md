# 影译 YingYi

Android 离线实时翻译工具：把手机正在播放的声音（任意 App，系统内录）识别成文字、**全部离线**翻译成中文字幕，以可拖动的悬浮窗显示。识别与翻译模型全部运行在手机本地，**不联网、不上传任何声音**。

## 功能

| 功能 | 说明 |
|---|---|
| 视频翻译 | 内录任意 App 的播放声音（抖音 / B站 / YouTube / 本地播放器），实时出中文字幕悬浮窗 |
| 对话翻译 | 手机放中间，单麦克风双向互译，自动判断说话方向，双语气泡 + 语音播报 |
| 同声传译 / 智能听译 | 内录或麦克风拾音，识别 → 翻译 → TTS 播报 |
| **耳机同传** | 戴蓝牙 / 有线耳机边听边译，译文直接播到耳机；支持「耳返模式」 |
| **外接设备（翻译机模式）** | ESP32 等外设按 `QYDEV/1` 协议接入：设备拾音、手机识别翻译、译文回传设备喇叭 |
| **跨应用翻译三件套** | ① **输入法**：在任意 App 里直接输入并翻译 · ② **翻译悬浮球**：划词即译 · ③ **AI 润色**：译文一键润色 |
| 文本翻译 | 输入文字离线翻译；模型未就绪时可选云端先出结果 |
| 会议录制 | 边录边转写，WAV 录音与 SRT 字幕时间轴对齐，可导出 TXT / SRT / 分享录音 |
| 离线翻译 | 自研离线翻译包，覆盖官方索引缺失的语向 |
| 拍照翻译 | 离线 OCR 识别图片文字并翻译 |

- **55 种语言 / 106 个翻译语向**（经英语枢纽），界面默认中文 ⇄ 英语
- 悬浮字幕窗可拖动、缩放、双击还原，带电平指示
- 4 套配色主题 × 深色 / 浅色 / 跟随系统
- 支持应用内在线更新
- 拍照翻译用 **ONNX PP-OCRv4**（检测 + 识别 + 分类三合一），完全离线、体积比常见的 MLKit 方案更小
- 🔴 v0.22.0 起已内置中英双向离线模型（APK 约 128MB）⇒ 国内可正常下载安装离线包

## 系统要求

Android 10.0 及以上。

## 下载安装

1. 到 [Releases](https://github.com/zcf-AI2026/yingyi/releases) 下载最新的 `YingYi-*.apk`
2. 安装时允许「安装未知来源应用」
3. 首次使用某语言时，App 内会自动下载对应的识别 / 翻译模型（也可在「资源包管理」中导入）

## 在线更新

App 内「我的 → 检查更新」会检查本仓库的 `version.json`，有新版本时可直接在 App 内下载升级，已下载的语言模型全部保留。

## 外接设备（翻译机模式）

手机与外设需在**同一 WiFi**（手机热点或同一路由器）。外设按 `QYDEV/1` 协议接入，手机端监听 `51777`：

```
外设 ──① 上行 PCM（设备拾音）──▶ 手机 51777
外设 ◀──② 下行 PCM（译文播报）── 手机
```

- 设备连上后先发一行 ASCII 握手：`QYDEV/1 NAME=... BATT=87 DOWN=51778`
- 手机回一行 `OK 16000 1 16`（16kHz / 单声道 / 16bit 小端）
- 握手后为**裸 PCM**（无帧头），设备侧无需自己做端点检测，手机用自适应 VAD 自动断句
- 下行端口由设备在握手里声明；设备不做 AES / CRC —— TCP 层已自带校验与重传
- 需防他人接入时，可在握手行加 `TOKEN=<配对码>`，App 侧校验（不带 TOKEN 的旧设备仍放行）
